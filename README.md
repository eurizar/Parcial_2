# Registro Médico

**Registro_Medico** es una aplicación Java Swing que permite gestionar pacientes médicos. Permite guardar, buscar y listar pacientes en una base de datos SQL Server.

## 🧩 Características

- ✅ Guardar pacientes con nombre, teléfono, alergias, dirección y tipo de sangre.
- 🔍 Buscar pacientes por ID.
- 📋 Listar todos los pacientes registrados.
- 🗃️ Conexión a base de datos SQL Server.
- 🎨 Interfaz gráfica desarrollada con Swing.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Java (JDK 8 o superior)
- **Entorno de desarrollo:** NetBeans
- **Base de datos:** Microsoft SQL Server
- **Conexión a base de datos:** JDBC
- **Interfaz gráfica:** Java Swing
